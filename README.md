# AgentRouter KW2 🚀

AI Agent Orchestration Platform - versi KW 2 dari agentrouter.com

![AgentRouter](screenshot.png)

## 🌟 Features

- **Multi-Agent Support** - 6 AI agents (GPT-4, Claude, Gemini, Llama, Mistral, Cohere)
- **Smart Routing** - Auto-route ke agent terbaik berdasarkan cost/latency/quality
- **Live Playground** - Test agents real-time
- **Beautiful UI** - Modern gradient design dengan Tailwind CSS
- **Responsive** - Mobile-friendly
- **Real-time Stats** - Track requests, latency, active agents

## 🚀 Quick Start

```bash
# Clone repo
git clone https://github.com/rickyananda/agent-router-kw2.git
cd agent-router-kw2

# Open in browser
python3 -m http.server 8000
# Visit http://localhost:8000
```
